# Touch Driver Fixer 

チャレンジパッドNextにおいて、タッチパネルのフリーズ対策（自動復旧）と物理ホームボタンの無効化を1本に一本化した、統合Magisk / KernelSUモジュールです。

本バージョン（v2.0）より、アプリごとに最適な挙動をユーザー自身が選べる**専用の設定画面（WebUI）が初搭載**されました！

> 💡 **実機動作確認済み環境**
> - 対象端末: チャレンジパッドNext (NVT)
> - 動作ベース: Pixeltouch v2.1.0 

---

## 🌟 主な機能

- **タッチパネル自動最適化・即時復旧**
  - パームリジェクション設定やタッチパネルの電源制御を常時ONに固定し、フリーズの発生自体を劇的に低減。
- **物理ホームボタンの無効化**
  - 手が当たってアプリが閉じてしまう誤操作を完全に防止。
- **【NEW】アプリ別モード個別指定（WebUI初搭載）**
  - アプリごとに「高速モード」と「安定モード」をスイッチ可能。adivenxnataly氏版「KsuWebUI」に完全対応。
- **設定データの永続化（アップデート対策）**
  - 設定ファイルをモジュール外（`/data/adb/touch-reset_config.json`）に保存するため、モジュールの更新や再起動で設定が消えることはありません。

---

## 📱 初搭載の設定画面（WebUI）について

KernelSU等のマネージャーアプリから本モジュールのカード、または「アクション」をタップすることで、専用の管理画面がスマートに起動します。

- **高速モード（デフォルト）**: 復旧処理が一瞬で終わります。未設定のアプリは自動でこれが適用されます。
- **安定モード**: 処理に約3秒かかりますが、重いゲームや動画アプリが稀に強制終了（クラッシュ）してしまう現象を確実に防ぎます。

*便利な「一括検索クリア（×）ボタン」や、スマホの「戻る」ジェスチャーで検索欄をサッとリセットできる、公式アプリさながらの快適なWebUIに仕上がっています（画面内の「？」ボタンからいつでも説明を読めます）。*

## 📦 インストール・アップデート方法

1. GitHubの Releases から最新の `Touch-Driver-Fixer v2.0.zip` をダウンロードします。
2. KernelSU / Magisk / APatch 等のマネージャーアプリからインストールしてください。
3. インストール完了後、端末を再起動してください。
   *(※v1.1等の古いバージョンからアップデートする場合も、以前の設定は安全な場所へ自動的に引き継がれます)*
