# Touch-Driver-Fixer

特定の端末（チャレンジパッドnext）で発生する、タッチパネルが一定時間で無効化される現象（通称：ひまっせタイマー）を解決するためのMagiskモジュールです。

---

## 📌 概要

ホームキー（`0066`）のタップをバックグラウンドで常時監視します。ホームキーがタップされたことを検知すると、タッチパネルドライバー（`NVT-ts`）のアンバインド（切断）および再バインド（再接続）を自動的かつ一瞬で行い、タッチパネルの挙動を正常な状態にリセット（最適化）します。

Magiskの `service.sh` を利用してバックグラウンドで軽量に動作するため、ユーザーが手動でアプリを起動したり、コマンドを入力したりする必要はありません。

---

## 🔗 おすすめの併用モジュール

本モジュールを快適に使用するため、作者が公開している以下のモジュールとセットで導入することを強くおすすめします。

* **HomeButton Disable Module**
  https://github.com/kiyotti1/HomeButton-Disable-Module

※上記のモジュールを一緒に導入することで、「ホームキーをタップしたときに画面がホームに戻ってしまう誤動作」を完全に防ぎ、純粋にタッチパネルの復旧（リバインド）トリガーとしてホームキーを快適に使えるようになります。


---

## ✨ 特徴

* **自動リバインド機能**: ホームキーをポンとタップするだけで、裏で自動的にドライバーが再読み込みされます。
* **二重起動防止**: スクリプトの多重起動を防ぐ競合防止処理が入っているため、システムに負荷をかけません。
* **ログ機能搭載**: 正常に動作しているか、いつリバインドが走ったかをシステムログで確認できます。

---

## 🛠️ 動作確認（ログの確認方法）

本モジュールが正常に動いているか、またリバインドが実行されたかは、PCのADB環境または端末上のターミナルアプリから以下のコマンドで確認できます。
```bash
logcat -s HOMEKEY_MOD
````


> [!NOTE]
> 起動時に「監視サービスがバックグラウンドで起動しました」と表示され、ホームキーを叩いた際に「リバインドを実行します」と記録されれば正常に動作しています。
