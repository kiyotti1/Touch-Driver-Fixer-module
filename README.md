# Touch Driver Fixer

<img width="1920" height="1200" alt="Image" src="https://github.com/user-attachments/assets/ba0023de-c232-46d7-b027-6d02e048fcbd" />

チャレンジパッドNextにおけるタッチパネルのフリーズ対策（自動復旧）と、画面更新サービス（物理ホームボタンの無効化・タッチ監視ループ）を一本化した、統合Magisk / KernelSUモジュールです。

本バージョンでは、お使いの端末に実際にインストールされているアプリ（サードパーティ製アプリおよび主要なGoogle系アプリ）だけを自動判別してスマートに一覧表示する専用の設定画面（WebUI）を搭載しています。

---

## 🌟 主要機能
- **画面設定の最適化および、設定**
  - インストール時に、タッチパネルの最適化を行います。また、uiの設定より、数値を変えることが可能です。
- **アプリ別のリカバリモード個別指定**
  - **高速モード（リバインド）**: ドライバを瞬時に再バインドして一瞬でタッチを復旧させます。
  - **安定モード（セルフテスト）**: 重いゲームや動画アプリなどで稀に発生するアプリの強制終了（クラッシュ）を完全に回避し、安全にタッチを復旧させます。
- **インストール済みアプリへの自動最適化**
  - 膨大なシステムアプリのノイズを排除し、実際にインストールされているアプリ（主要Googleアプリ5種、LINE、LINE MUSIC、BOOK☆WALKER、その他サードパーティ製アプリ）のみを綺麗にマッピングして表示・設定できます。
- **ハードウェア自動判別と各種最適化**
  - NVT（Novatek）および FTS（FocalTech）ドライバを自動で判別。パームリジェクション感度の調整、画面プロファイル最適化、CPUガバナー（schedutil / performance / powersave）の切り替え機能を備えています。
