# Touch Driver Fixer v3.0

<img width="1920" height="1200" alt="Image" src="https://github.com/user-attachments/assets/ba0023de-c232-46d7-b027-6d02e048fcbd" />

チャレンジパッドNextにおけるタッチパネルのフリーズ対策（自動復旧）と、画面更新サービス（物理ホームボタンの無効化・タッチ監視ループ）を一本化した、統合Magisk / KernelSUモジュールです。

専用の設定UI（Web UI）を備え、各種設定のカスタマイズが可能です。

---

## 🌟 主要機能

- **ドライバ制御の刷新と超高速復帰**
  - タッチドライバ制御および判定ロジックを大幅改善。フリーズ発生時にドライバの高速リセットをダイレクトに行うことで、**画面描画を崩さず瞬時にタッチを復旧（超高速復帰）** させます。
- **ハードウェア自動判別 (NVT / FTS)**
  - NVT（Novatek）および FTS（FocalTech）ドライバの接続デバイスノードを厳密に自動判別。環境に応じた最適な処理を適用します。
  - **※ 本モジュールは主に NVT ドライバ向けに設計・最適化されています。FTS ドライバ環境では一部機能（パームリジェクション感度設定など）がご利用いただけません。**
- **各種システムの最適化**
  - パームリジェクション感度調整（NVT専用）
  - デバイス Power Control ノード制御 (`on` / `auto`)
  - 画面プロファイル最適化 (`soc:touch`)
  - CPUガバナー切り替え (`schedutil` / `performance` / `powersave`)
