# Touch-Driver-Fixer

特定の端末（チャレンジパッド Next）で発生する、タッチパネルが一定時間で無効化される現象（通称：ひまっせタイマー）を軽減・復旧するための Magisk モジュールです。

---

📌 概要

ホームキー（"KEY_HOME / 0066"）をバックグラウンドで監視し、ホームキーが離されたことを検知すると、自動的にタッチパネルの復旧処理を実行します。

最新版では従来のドライバ再バインド方式ではなく、Novatek（NVT）タッチドライバの SelfTest 機能を利用した復旧方式を採用しています。

また、起動時に Palm Reject 設定およびタッチデバイスの電源管理設定を適用し、タッチパネルの安定化を行います。

Magisk の "service.sh" を利用してバックグラウンドで軽量に動作するため、ユーザーがアプリを起動したりコマンドを入力したりする必要はありません。

---

✨ v1.1 の変更点

- 復旧方式を Driver Rebind から SelfTest 方式へ変更
- ホームキーを離した瞬間に復旧処理を実行
- 起動時に Palm Reject を自動適用
- 起動時に Runtime Power Control を自動設定
- 二重起動防止処理を改善
- 復旧時の副作用を低減

---

✨ 特徴

- ホームキーを押して離すだけでタッチ復旧を実行
- アプリ終了や画面乱れなどの副作用を抑制
- 起動時にタッチ関連設定を自動最適化
- バックグラウンドで軽量動作
- ログ出力による動作確認が可能

🔗 おすすめの併用モジュール

本モジュールを快適に使用するため、作者が公開している以下のモジュールとの併用をおすすめします。

HomeButton Disable Module

https://github.com/kiyotti1/HomeButton-Disable-Module

ホームキー押下時にホーム画面へ戻る動作を無効化し、ホームキーを純粋なタッチ復旧トリガーとして利用できるようになります。
